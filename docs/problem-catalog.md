# Catálogo inicial de problemas Codeforces

Curadoria gerada em 2026-07-29 a partir da API pública `problemset.problems` do Codeforces. O critério base foi: problemas com rating oficial, tag compatível com a categoria e alta quantidade de resoluções como aproximação de valor didático/popularidade.

Fonte primária dos metadados: https://codeforces.com/api/problemset.problems

Use o código no padrão do repositório trocando `71A` por `CF_71A`, `580C` por `CF_580C`, etc.

## Como usar este catálogo

- Para treino por tema: escolha uma categoria e suba 100 ou 200 pontos por vez.
- Para simular competição SBC/ICPC: monte sets mistos com 8-12 problemas, escondendo as tags dos competidores.
- Para upsolve: depois de cada contest virtual, mova os problemas errados para a categoria correspondente e registre o aprendizado no README da pasta do problema.

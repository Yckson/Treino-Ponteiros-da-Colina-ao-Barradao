# Problemas

Coloque aqui os PDFs dos problemas do Codeforces, organizados por:

```text
problems/<dificuldade>/<rating>/<categoria>/<codigo>/
```

Exemplo:

```text
problems/iniciante/800/strings/CF_71A/
```

Sugestão de conteúdo para cada pasta de problema:

```text
CF_71A/
├── statement.pdf
└── README.md
```

O arquivo `README.md` pode guardar link do problema, tags, ideias de solução e observações do treino.
